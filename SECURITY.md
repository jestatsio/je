# Security

Report a suspected vulnerability privately through GitHub security advisories
for this repository. Do not open a public issue for a vulnerability.

Never include credentials, prompts, memory text, task history, private file
contents, or another person's data in a report, issue, pull request, log, or
test fixture.

The native core is experimental and pre-1.0. Public source does not grant
access to any hosted Studio service, account, workspace, or data.
