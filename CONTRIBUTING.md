# Contributing

Contributions are accepted under Apache-2.0 unless a file says otherwise.

Keep changes small and tested. Run `swift test` before opening a pull request.
Name the Python oracle behavior or roadmap decision a port is meant to match.

Do not add credentials, prompts, memory text, task history, private paths from
a real machine, or another person's data to code, tests, fixtures, issues, or
pull requests.

Host-only workspace, network, and service-control code does not belong in the
public user artifact.
